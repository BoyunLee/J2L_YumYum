# Photo Placeholders

이 폴더에는 최종 발표자료에 사용할 팀 사진과 개인 사진을 넣습니다.

권장 파일명:

- `team-photo.jpg`: 개발 후기 슬라이드의 팀 사진
- `member-01.jpg`: 팀원 1 개인 사진
- `member-02.jpg`: 팀원 2 개인 사진
- `member-03.jpg`: 팀원 3 개인 사진
- `member-04.jpg`: 팀원 4 개인 사진

사진을 넣기 전까지 Gamma 프롬프트에서는 이미지 자리표시자를 사용합니다.

## 사진 사용 기준

- 팀 사진은 개발 후기 슬라이드에 1장만 크게 사용한다.
- 개인 사진은 선택 사항이며, 넣는 경우 역할/회고와 함께 작은 카드 형태로 배치한다.
- 공개 발표자료에 사용할 수 있는 사진인지 팀원 동의를 확인한다.
- 사진 파일명에 전화번호, 학번, 개인 계정명 등 식별 정보를 넣지 않는다.
